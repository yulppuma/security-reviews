# Security Reviews

A curated collection of smart contract and application security reviews, audit findings, exploit research, and vulnerability analysis performed by [Yul Puma](https://github.com/yulppuma).

This repository serves as a public archive of my security work across:

- Smart contract audits
- Personal security research
- Competitive audit contests
- Practice reviews
- Protocol deep dives
- Exploit reproductions
- Post-mortem analysis
- Vulnerability writeups

The primary focus is Web3 and blockchain security, with emphasis on Solidity, EVM protocols, DeFi architectures, and secure smart contract design.

---

## Goals

The purpose of this repository is to:

- Document my security research journey
- Publish structured audit findings and reports
- Practice identifying real-world vulnerabilities
- Improve secure development and review methodologies
- Share knowledge with the broader security community
- Build a transparent portfolio of security-focused work
